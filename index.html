Frequently Asked Questions

Find answers to common questions about the GitHub Management Bot

How do I set up the bot?

  • Clone the repository from GitHub
  • Install dependencies using npm or pip
  • Configure your GitHub and Telegram tokens
  • Run the bot and start managing GitHub from Telegram

Is my data secure?

  • All communications use HTTPS encryption
  • Tokens are stored securely and never logged
  • Open source code allows community security audits
  • No personal data is shared with third parties

What commands are available?

  • /status - Check repository status
  • /issues - List open issues
  • /prs - View pull requests
  • /notify - Configure notifications
  • See the README for the complete command list
